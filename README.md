A Tile map editor that crashes every time you open a file 2x and is held up by hopes and prays.

what it is:
Tile map editor will allow users to edit tiles on a canvas.

Features:
Camera controls:

A – Move the camera to the left

D – Move the camera to the right

S – Move the camera down

A – Move the camera up

Q – Zoom the camera out

E - Zoom the camera in


Tools controls:

R – Toggle rotate tiles

T – Toggle texture tiles mode

C – Toggle colour tile vertices mode

Z - delete tile chunk

X - create tile chunk


Left click – changes the state of a tile

Third party libraries used:

imgui-docking: UI

GLM: math library

GLEW: OpenGL

GLFW: multi platform window
